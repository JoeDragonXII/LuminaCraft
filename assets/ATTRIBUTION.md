- `branding/lumina-shared-icon-v9-landscape.png`: LuminaCraft mountain / L / flash artwork. Original work created for this project with OpenAI image generation, 2026-10-17; distributed under the root MIT license.
- `app-icon/icon-256.png`, `app-icon/luminacraft.ico`: size variants of that approved artwork, produced by `scripts/build-icons.py`; no changes to the composition; same license.
- `yunet.onnx`: YuNet face detector, Shiqi Yu and contributors, MIT. Source: https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet. License: `YUNET-LICENSE.txt`.
- `style-map-reference.jpg`: public-domain Ansel Adams photograph inside a LightCraft screenshot. Full source, attribution and licenses: `STYLE-REFERENCE-LICENSE.md`.
- `map-space-policy.txt`: original application prompt policy, root MIT license.

Upstream assets retain their original attribution and license files under `upstream/lightcraft` and `vendor`.
