# AI 风格化

主 App 的最后一步支持将已有提示词封装为风格按钮。首版使用 OpenAI 官方 Images 编辑协议；DeepSeek 原生出图未启用，不会把文字响应当成生成图片。

## 使用

1. 重新运行 `启动 LuminaCraft.cmd`，点击顶部“AI 设置”。
2. “OpenAI 服务”中新增配置，填写名称、API 基础地址、图片模型 ID 和 API 密钥。官方基础地址为 `https://api.openai.com/v1`；默认图片模型为 `gpt-image-2.5-sunburst`，可改成你的账户有权限使用的 GPT Image 编辑模型。
3. 设为默认服务，或在“风格模板”中为每个模板指定服务。新增风格名称，粘贴完整提示词，点击“保存配置与模板”。支持编辑、复制、删除模板及多套服务配置。
4. 将照片载入工程，完成调色和人像修饰，先保存工程。切到“风格化”，选择模板，点击“生成风格版本”。本次提示词可临时调整，不会自动覆盖模板；空格和换行原样提交，不做分析或改写。
5. 在右侧“历史版本”中选择结果，通过左侧“生成前 / 后”切换该版本实际发送的输入与结果；“当前成片”返回实时编辑预览。可从这里或“导出与展示”的 AI 成片入口另存 PNG/JPEG。导出拒绝覆盖已有文件。

## 风格化单页工作台

参考用户确认的五区草图和浅色界面参考，风格化页独立采用暖白底色、细边线、圆角面板与轻微阴影；中央看图区域保留中性深灰。基础/人像现已与风格共享浅色修图工作台；照片库和导出页面保持现有布局与深色风格。详见《修图工作台》。

- 左侧为照片选择弹窗、上一张/下一张、适应窗口、缩放及生成前后对比。
- 中央完整显示当前照片或所选版本，不强制裁切；放大后可滚动。切换照片清空旧风格预览与补充地点。
- 大图下方显示真实任务阶段：准备、生成、保存、完成、取消、失败。等待使用旋转指示，不估算百分比；取消仍受服务返回时间约束。
- 底部横向风格卡片只选择风格，不立即生成。内置地图卡片始终第一项，显示授权样片并明确标记“风格示意 · 非生成效果”；自定义风格没有样图时只显示名称。
- 右侧为所选风格、地点资料、生成、历史版本、导出；自定义风格的本次提示词以及服务/生成详情折叠展示。内置地图规则没有编辑框。
- 默认窗口为1380×900，最小980×680。宽度低于1160时右栏默认收起，可点击“操作”展开；已选风格、版本和任务不受栏位收起影响。

真实任务可在浏览其他照片时完成，结果始终绑定提交时的照片与工程。当前照片没有匹配版本时，对比和风格导出不可用；导出入口再次检查照片归属。界面任务状态、栏位与样图纹理不写入工程，不需要迁移旧工程格式。

样片许可见 `assets/STYLE-REFERENCE-LICENSE.md`。本页尚未接入真实地图服务或地图截图附件，界面示意与本地协议夹具均不代表实际模型效果。

连接测试只读取模型列表，不发送照片、不验证实际出图效果。生成按钮才会向所选服务提交图片任务，可能产生 API 费用。

## 保存与任务行为

- 配置与模板默认在 `%LOCALAPPDATA%\LuminaCraft\ai\settings.json`；密钥单独存入 Windows 凭据存储，不进入配置 JSON、工程、回执或日志。`LUMINACRAFT_AI_DIR` 可指定隔离配置目录。更换地址需要重新填写密钥，凭据按配置及地址隔离。
- 输入为当前照片的调色、裁剪、修饰后 sRGB PNG 副本，长边不超过2048像素，不附原始 EXIF/GPS。模型返回的尺寸以实际图片为准，不承诺原 RAW 分辨率或原照片像素完全不变。
- 每次任务固定照片/虚拟副本身份、编辑指纹、提示词和模型。远程线程与预览线程独立；处理中可以切换照片或修改参数。结果仍归属提交时的照片版本，不覆盖后续编辑。
- 结果位于工程目录 `ai-style/<任务ID>/`，包含 `input.png`、`output.png` 和 `result.json`。工程保存风格记录；即使完成任务后尚未保存工程便关闭，重开原工程也会发现完整回执。损坏的恢复回执保留并跳过；图片缺失或被更改时不能预览/导出，但仍可编辑原照片。
- 保存新工程目录时，已有记录继续引用原位置的资源；需要搬迁时保留原工程的 `ai-style` 资源路径。首版没有自动打包/迁移工具。
- 删除服务/模板不删除生成历史。任务不自动重试；认证失败、限流、超时和无效图片明确报错。取消会停止接收处理结果，但不能保证服务端停止计费；正在进行的网络请求最多等待300秒，期间不会启动第二次生成。

## 验证范围

已完成本地 HTTP 协议夹具、Windows 临时凭据、提示词原样发送、当前渲染输入、失败/限流/超时/取消、结果校验、工程恢复及禁止覆盖导出测试。真实 Windows 窗口已点击生成/对比按钮，并验证重复点击和未保存回执恢复。夹具结果不是 AI 模型效果。

真实 OpenAI 账户出图需在 App 内配置有效密钥及可用模型后验收。本轮没有取得用户密钥，也没有声称实际模型生成成功。私有验收脚本/截图不进入发行包。

协议参考：[OpenAI Images 编辑接口](https://developers.openai.com/api/reference/resources/images/methods/edit)。


## 内置地图空间背景处理
风格化首项默认选中“地图空间背景处理”。规则编译自 assets/map-space-policy.txt，不进入用户模板 CRUD，不提供本次提示词编辑，修改规则需改代码并重建。使用默认 AI 服务。仅地点资料可填写；原片 GPS 在后台读取并随提示词明确发送，原片/XMP 不改写。无有效 GPS 且无地点时，提交图片前返回补充提示；地名参考始终按近似区域处理。
当前接入是受固定规则约束的 AI 图片编辑，不是确定性地图合成器；尚未接入地图服务、地图截图附件或坐标输入解析。GPS 不代表获取了真实路网，规则要求省略不能核实的地理细节。尚未真实模型出图验收，不能保证模型逐像素保留主体或地理准确；需对比输入后再导出。
