# Lightroom 目录实验导出

主页面「目录 → 导出 Lightroom 目录 .lrcat（实验）…」。先选旧 `.lrcat` 作为只读结构模板，再选一个不存在的目标文件，确认「导出并回读验证」。可选只导出选片，自动附带虚拟副本的原始记录。请关闭使用模板目录的 Lightroom；有活动 WAL、journal 或锁时拒绝导出。

目前支持用户提供旧目录的内部版本 `1400000`（CRS `17.0.0`）。输出为实际 SQLite `.lrcat`，不是把 `.lumcat` 改名。模板仅提供表／索引／触发器结构和格式版本；在全新的数据库生成当前照片库的数据，不复制模板的照片记录、账号、同步信息、预览或 Adobe 配置内容。模板与原片不写入，目标禁止覆盖，取消／失败不提交半成品。提交使用同盘硬链接，不支持硬链接的存储会报告失败，建议先存到本机 NTFS 磁盘。

这版保存照片原路径、评级、旗标、标准颜色标签、拍摄时间、分层关键词、普通集合及文件夹层级、集合成员、虚拟副本名称与关联。仅导出未删除照片；选中虚拟副本会附带主记录。智能集合变为当前成员快照，快速集合变为普通集合；关键词作为名称及层级保存，额外同义词／人物属性／导出选项尚未映射。离线原片路径仍保留；另一台电脑需有原片并可重新定位。

显影参数、朝向／裁切、蒙版、人像修图、历史、版本快照、堆栈、AI／降噪结果和完整 IPTC／EXIF 元数据尚未保真映射。完整编辑请同时另存 `.lumcat`，不要把这版 `.lrcat` 当作完整工程备份。自定义颜色名称会映射为标准颜色名。预览在接收端重建；不生成 `.lrcat-data` 或 Adobe AI 数据。

导出先检查 SQLite 完整性，再用随附 LightCraft 的只读 `.lrcat` 读取器逐项核对照片路径、评级、旗标、颜色、关键词、主副本关系、集合名称／层级／成员，通过后才提交。初步验收另调用完整版 `library.importLightroom` 实际导入隔离库、比较字段并保存重开。这个标准已通过；尚未在 Adobe Lightroom Classic 实际打开，不承诺 Adobe 全面兼容。

验证工具：`examples/lrcat_roundtrip.rs` 使用指定真实模板的结构及本地生成图片，不操作真实照片。运行 `& .\scripts\cargo.ps1 run --example lrcat_roundtrip -- "旧目录路径.lrcat" "新的私有证据目录"`。生成 128 条记录（3 原片、125 虚拟副本），逐项核对、重开，并检查模板／原片哈希及模板修改时间未变。证据含合成图片路径，应留在私有目录。
