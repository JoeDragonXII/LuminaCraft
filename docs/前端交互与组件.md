# 主 App 交互与共用组件

继续使用 Rust/egui；界面方向为石墨外壳、薄荷选中态、暖白文字、中性深灰照片画布、少量文字和同一套圆角。Impeccable用于信息分组与视觉验收，Emil Design Engineering用于操作反馈和键盘细节，Motion的通用规范用于克制动效；没有引入React、Motion运行时或网页组件库。

## 流程

| 场景 | 行为 |
| --- | --- |
| 照片库新选照片 → 修图 | 载入活动照片，恢复上次修图分类；已载入照片保留工程参数 |
| 照片库新选照片 → 导出 | 载入活动照片的修图结果，离开旧历史成片预览 |
| 无新选片的页面往返 | 保留当前照片、缩放与分类；不多做渲染 |
| 多选包含已有及新照片 | 新照片追加，载入后仍选提交时的活动照片 |
| 历史成片 → 当前照片 | 显式“查看当前照片”，不把修图参数再次套到成片 |
| 保存工程 | 更多内保存参数和历史，Ctrl+S；图片导出另行执行 |

## 组件与约束

- 品牌使用确认的 v9 山水图标，顶部30px；主窗口、高级窗口和双击exe入口使用同一图稿。PNG及16–256px ICO由`scripts/build-icons.py`打包，编译时嵌入，不依赖外部图标路径。
- 修图分类与“当前成片”导航复用`chrome::control`，选中即时响应，按下、禁用与键盘焦点跟随共用组件。

- `chrome::icon_button`、`icon_button_width`、`text_button`：共享34px高度、居中、圆角、焦点环、禁用和按下反馈。照片库星级/标记/颜色为等宽三个下拉，选项仅在展开时呈现。
- 上游`icons::Icon`：使用同一矢量图标语言，替换Unicode加号/色点等控件装饰。
- `egui::Popup::menu`：统一图标菜单、添加入口和更多菜单；视图、筛选、排序、选择按需展开。
- `TextEdit`、`Slider`和已有参数行：继续复用原生输入与渲染/操作方法。
- 照片库toolbar常驻单行；1380×900和980×680以及窄窗展开右栏都不能换行、遮挡或溢出。
- 照片主体不做进出场、缩放或面板尺寸动画。选中和键盘反馈立即生效，指针悬停至多120ms；系统减少动效/环境覆盖仍禁用过渡。
- 主导航只有照片库、修图、导出。目录与保存工程留在更多，导出页不出现修图工具。
- 基础/人像页底部固定[操作历史](操作历史.md)，与参数分开滚动。复用每张照片的撤销栈，不与工程版本、AI生成版本混为一类。

## 验证

`scripts/cargo.ps1 check/test/build`；主程序测试覆盖共用控件键盘Enter激活、导航对比度与照片库基础交互。私有原生脚本覆盖所有主页面大小窗口、菜单、星级、上下文往返与活动照片归属；编辑、风格生成与本地导出分别回归。照片和工程均使用隔离临时夹具，不向网站写数据，不将协议测试视为实际AI效果。


## 石墨 / 薄荷 / 暖白配色（2026-10-16）

主App参考用户色板统一为深色：石墨 #303531 用于面板，外壳 #232825、照片画布 #1D201F 分层，暖白 #FFF2DF 用于正文，薄荷 #97FE98 用于当前导航、主要可用操作和焦点。照片画布保持中性深灰；只改变界面材质与状态，不给照片添加滤色。

语义token集中在src/chrome.rs：SURFACE/PANEL/CANVAS/CONTROL/HOVER/SELECTED、INK/MUTED、ACCENT/ON_ACCENT、WARNING/ERROR。内置egui控件使用Dark主题和统一填充/文字/光标/选区；自绘导航采用薄荷底深字，列表和历史使用深绿色选区。侧栏、卡片、菜单、输入框、对话框、错误提示一起迁移；未就绪的生成按钮使用普通禁用外观，不能以亮绿色暗示可操作。键盘焦点在薄荷选项上使用深描边，在深色控件上使用薄荷描边。既有评级五色保留原有含义；上游高级窗口保持其自身外观设置。

扩展现有颜色对比测试，覆盖语义前景与五种底色，以及选中/悬停/禁用和过渡帧，文字对比至少4.5:1。仍采用原有圆角、布局、缩放和减少动效策略；底栏固定高度，普通预览不恢复加载动画。


## 苹果风格排版（2026-10-16）

主App通过src/typography.rs集中设置字体角色，在Windows运行时读取系统字体，不复制系统字体文件到发行包。正文/按钮13px：Segoe UI Variable（wght400、opsz13）优先，中文为Microsoft YaHei UI（msyh.ttc索引1），最后保留egui内置回退。品牌/标题使用真实Segoe UI Semibold，中文仍用常规UI字重，通过字号与留白建立层次，避免粗黑中文。辅助文字11.5px，主标题17px；自绘toolbar与全局egui控件采用同一套body字号。

数值输入独立UI Numbers字体族，使用系统Segoe UI常规字体的等宽数字；DragValue全局绑定Value样式。保持原有68×30数值区、34px按钮、40px修图分类及固定底栏，字体不参与过渡动画。字体数据一次读取并共享Arc；缺失字体时保留已加载中文与egui默认回退，不从网络下载字体。高级窗口不在本轮迁移范围。

新增实际字体族排版与000000/111111等宽测试，图库交互测试上下文同步安装生产字体。原生验收继续覆盖两个窗口尺寸、菜单、空态、跨页上下文和禁用状态。
