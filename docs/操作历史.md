# 修图操作历史

基础和人像页的右侧下方提供“操作历史”，与上方参数分开滚动。当前步骤高亮，撤销后的步骤变淡但仍可点击重做。也可以继续使用顶部撤销/重做及Ctrl+Z、Ctrl+Shift+Z。

它直接复用主App已有的每张照片独立撤销/重做栈，没有另建一套参数恢复引擎：点击步骤会移动既有栈并只渲染最终状态，恢复包括人像修饰在内的完整EditState，并同步裁剪控件。最多保留100次操作；连续拖动滑杆或曲线合为一次，失败和没有参数变化的命令不生成步骤。回退后继续编辑会替换后续分支。没有照片时显示提示，不伪造历史。

| 功能 | 保留范围 |
| --- | --- |
| 操作历史 | 主界面本次打开期间、按照片独立记录；不随工程保存 |
| 工程版本 | “保留当前版本”创建命名状态；保存工程后可跨次恢复 |
| AI风格版本 | 风格页自己的输入/生成结果版本；独立于参数操作历史 |

步骤名称概括主要变化（曝光、曲线、人像修饰、蒙版等），不是逐字段审计日志。会话起点也不一定是原片默认参数，例如导入XMP或打开已编辑工程时。高级编辑窗口仍使用LightCraft自身的历史；主界面不冒充已经导入完整版的全部逐步历史。

视觉行为参考固定开源快照中的LightCraft `crates/ui-egui/src/panels/right.rs`（当前/已撤销行）和PhotoCraft `crates/ui-egui/src/panels.rs`、`edit_history.rs`（历史游标与拖动合并）。未修改vendor，也未引入PhotoCraft图层文档作为照片修图历史。

照片库的星级、标记、颜色为同一行三个下拉。展开后分别出现清除及1–5星、入选/排除/清除、清除及五色；操作仍调用原有LibraryAction，遵循多选、活动照片与自动前进规则，不回写原片/XMP。
