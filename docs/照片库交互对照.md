# 照片库交互对照

顶部工具区为单行：视图入口、弹性搜索、结果数量（宽度足够时）、筛选、排序及选择菜单。控件统一34px高并垂直居中，窄窗口收敛信息，不换成两行。星级/标记/颜色在筛选菜单，排序字段/方向在排序菜单，全选/清除选择/标记后自动前进/缩略图大小在选择菜单；原有快捷键继续可用。重置筛选保留当前相册、文件夹及最近删除范围，扫描和错误反馈仍显示。

左侧添加照片、文件夹及添加选项统一到“添加照片…”菜单。右侧星级、标记、颜色收为同一行三个等宽下拉；点击后分别展开清除及1–5星、入选/排除/清除、清除及五色，不再常驻堆放三组控件。普通操作回执只在底栏显示，扫描和错误仍有就近反馈。

2026-10-14。范围是 LuminaCraft 的本地照片库管理与选片流程。基于固定版本 LightCraft 源码实现，参考 Lightroom Classic 的公开说明，不复制 Adobe 素材，也不宣称完整产品或画质等价。

选片按 [Lightroom Classic 官方快捷键](https://helpx.adobe.com/lightroom-classic/desktop/introduction-to-lightroom-classic/keyboard-shortcuts.html) 与 [浏览/对比说明](https://helpx.adobe.com/lightroom-classic/desktop/viewing-photos/browse-compare-photos.html)核对；相册和快捷收藏参考 [集合说明](https://helpx.adobe.com/lightroom-classic/desktop/organize-photos-in-lightroom-classic/photo-collections.html)。LightCraft 实现来源为 `crates/engine/src/view.rs`、`crates/engine/src/cmd/library.rs`、`crates/ui-egui/src/panels/grid.rs`、`compare.rs` 和 `docs/library-shortcuts.md`，均保持 vendor 原样。

| 操作 | LuminaCraft 当前行为 |
| --- | --- |
| 单击 / Ctrl 单击 / Shift 单击 | 替换 / 切换单张 / 按当前排序扩展范围。直接使用 LightCraft `Selection::toggle` / `extend_to`；活动照片单独描边。 |
| 右键 | 未选照片成为唯一选择；已选照片保留多选并变为活动照片。菜单中的修改范围与当前视图一致。 |
| G / E / Enter / 双击 | G 网格；E、Enter 或网格双击放大；放大双击返回网格。D 才进入调色，编辑中 G 返回照片库。 |
| C 对比 | 参考图与候选图并列；可交换、选定候选、前后切换候选。评级作用于活动照片。 |
| N 筛选 | 同时查看选中的照片，单屏上限 12 张；× 只从本轮候选中排除，不移出照片库。 |
| 非网格视图 | 提供可见区域加载的横向胶片栏，并加载最多 1600 像素的浏览预览。RAW 可以使用相机内嵌 JPEG，编辑仍使用传感器显影。 |
| 0–5 / [ / ] | 设置或逐张增减星级；网格作用于全部选中照片，放大/对比/筛选作用于活动照片。 |
| P / X / U，6–9 | 入选/排除/清除标记；红/黄/绿/蓝标签。紫色及清除标签在右键菜单和面板中。排除不会删除照片，网格会压暗其预览。 |
| Shift + 评级/标记/颜色/B | 执行后前进到下一张；“自动前进”作用于评级、标记与颜色。 |
| B / Ctrl+B | B 切换目标相册成员关系，未设目标时使用快捷收藏；全在目标中则全部移除，否则补齐成员。Ctrl+B 显示快捷收藏。 |
| 相册 / 智能相册 | 普通相册支持加入、移除、拖入、重命名、封面、目标相册、删除。智能相册从当前筛选生成，自动更新成员，可右键更新规则。 |
| Delete / Backspace | 普通相册内默认只移除成员；全部照片、文件夹、智能相册内则移出照片库。弹窗显示作用范围，确认使用冻结的 ID 列表。 |
| 右键移出照片库 | 明确移出 catalog，即使当前在相册中。原照片/XMP 保留，其他相册关系暂存；恢复后评级、关键词和原有成员关系保留。 |
| 恢复 / 重新导入 | 已移出视图提供恢复。重新导入默认恢复原记录，可关闭该选项以跳过；不创建重复记录，不清空原评级。 |
| 撤销 / 重做 | 按 LightCraft inverse `Op` 原子提交，Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y 和顶部按钮使用照片库历史。当前会话最多 100 次，不干扰调色工程的撤销栈。 |
| 关键词 | 添加或替换选中/活动照片的关键词，仅修改 catalog；保留其他元数据。搜索可匹配关键词。 |
| 视图保存 | 来源、筛选、排序、视图、活动照片、目标相册、导入选项自动保存到独立 `luminacraft-view.json`。多选持久化上限 2000 张；损坏配置保留并报告。 |

## 本项目保留的边界

- 原照片和原 XMP 只读，所以不提供删除磁盘文件、移动原片、重命名原片或回写 XMP。这是已确认的项目边界，不使用无效果的菜单项模拟。
- 移出后的恢复流程采用 LightCraft catalog 的 `SetDeleted` 语义，不声称与 Lightroom 的磁盘回收站完全一致。
- 浏览预览是原文件的浏览图，不等于独立工程的最终调色结果；照片库与工程内的“入选”目前仍独立。工程的 50 张限制保持，照片库不受此限制。
- 尚未接入：完整智能规则编辑器、堆栈、虚拟副本、自动监控导入、LR catalog 迁移、缺失原片重新定位、比较视图同步缩放/平移、原片 100% 浏览与批量工程导出。这些不标记为已复刻。

## 验证入口

`& .\scripts\cargo.ps1 test` 使用临时生成图片和独立库，覆盖实际 egui 点击/右键/拖入/快捷键、活动照片作用范围、冻结移除确认、相册与照片库的移除区别、inverse undo/redo、智能相册、关键词、视图重开和重新导入恢复。源码入口是 `src/library_workflow.rs`，UI 为 `src/library_ui.rs`，持久化为 `src/library.rs`。

原生截图仅使用生成夹具，位于 `verification/private/library-parity-{grid,loupe,compare,survey}.png`。大型用户照片库的性能与长期稳定性仍待验证。
