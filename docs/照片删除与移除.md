# 照片删除与移除

主页面和随附完整版使用相同的删除范围。照片库选择照片后按 Delete／右键移除，先选择操作；从磁盘删除还需要第二次确认。

| 操作 | 相册／照片库 | 磁盘 |
| --- | --- | --- |
| 从相册移除 | 只移出当前普通相册，其他相册和照片库保留 | 原片、XMP 保留 |
| 从照片库移除 | 标为最近删除，可以恢复或撤销 | 原片、XMP 保留 |
| 彻底移除记录 | 从最近删除彻底清理目录记录 | 原片、XMP 保留 |
| 从磁盘删除 | 移除同库中引用这个文件的所有记录及相册成员，包括虚拟副本 | 原片送入 Windows 回收站；原 XMP 保留 |

智能相册由规则决定成员，不提供“从相册移除”。只选择虚拟副本时不能删除原片；请移除副本记录，或明确选择它的原始记录再删除原片。原始记录与副本一起选择时，同一原片只处理一次。确认框会列出文件路径、文件数、受影响记录数，不随之后的选片改变。

磁盘删除是用户明确选择的管理操作，与调色、修图、导出不回写原片的边界分开。当前只支持 Windows 本机固定磁盘；网络路径、目录、符号链接／联接、缺失文件或发生变化的原片拒绝处理。使用 Windows IFileOperation 的回收标志，没有永久 unlink 的降级路径。实际回收站返回错误或取消时，目录记录保留。建议批量处理前先保存编辑工程。

打包导出时内嵌到目录的原片暂不支持直接磁盘删除，以免破坏资源清单和目录重开；这类照片仍可从照片库移除。普通外部引用原片及未被打包清单绑定的导入归档文件可使用磁盘删除。

确认前检查整个计划和文件内容；执行时再次核对原片，并先持久保存现有目录。每个文件成功移入回收站后，才移除其目录记录并保存；批次出错会停止，报告已经完成的数量。目录中 `DiskDelete/任务ID` 保存计划、受影响照片的元数据、逐文件意图／完成回执及结果，用于异常排查，不保存另一份原片。原片已经回收但后续目录写入失败时，会提示保存失败及保留恢复档案，不能将这类操作解释成整批成功或已回滚。

**磁盘删除不能用 App 的撤销恢复文件。** 为防止撤销旧操作重新添加失效引用，磁盘删除提交后清空当前照片库编辑撤销／重做记录。需要恢复时，从 Windows 回收站还原原片，再重新导入；本版不提供一键自动恢复旧相册、编辑及身份。元数据恢复档案留在原照片库工作目录，不打包进 `.lumcat`。其他工程／照片库若也引用同一原片，会变为原片离线；不会扫描或修改其他工程、其他照片库或 Lumina 网站。

测试只使用临时合成图片，不对真实用户照片进行磁盘删除测试。正常移除、取消和受影响副本关系有回归覆盖；原生窗口验收脚本与证据留在 `verification/private`。
