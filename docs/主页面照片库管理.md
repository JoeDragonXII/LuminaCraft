# 主页面照片库管理

主 App 的“照片库”页直接提供文件夹基础管理，不必打开完整版。仍使用同一 catalog 和独占库锁，管理操作不回写原片或原 XMP。

照片级删除新增明确范围及 Windows 回收站操作：参见 [照片删除与移除.md](照片删除与移除.md)。只有用户选择并单独确认从磁盘删除时才移动原片，文件夹移出仍保留原片。

## 左侧来源

- 所有照片、最近7天添加、留用（Pick标记）、最近删除，以及已有普通/智能相册和快捷收藏。
- 本地快捷入口：图片、桌面、下载和主文件夹。点击后选择要添加的照片文件夹，以原位置引用加入库，不复制/移动。它不是未导入目录的独立文件浏览器。
- 按拍摄日期浏览年/月/日；关键词树支持按层级筛选。
- 文件夹按磁盘和目录层级显示数量、颜色；默认简化共有父级链，可勾选“显示完整父级路径”。整个侧栏可滚动。侧栏来源统计按 catalog revision 缓存，避免逐帧重复建树。

## 文件夹右键

- **同步文件夹**：后台扫描后显示预览。默认添加新路径、关联内容一致的已移动原片；将仍缺失的记录移到最近删除默认关闭。选择关联时保留同一照片ID、虚拟副本、显影、评级和相册关系，不再重复添加同一路径。取消关联时可将新路径单独导入。
- **定位缺失的文件**：选择移动后的根目录，按原相对路径匹配，并验证 catalog 中的内容哈希。内容不符的项不关联；没有旧内容哈希的记录也不冒险关联。不会移动磁盘文件。
- **从图库中移除**：确认后将该目录及子目录的全部库记录移到最近删除，范围不受当前网格选片或搜索过滤影响。确认范围固定；catalog 在预览后改变则要求重新确认。操作可撤销，整盘/共享根移除不开放。
- **设置颜色标签**：保存文件夹颜色到同一 catalog，可撤销、重开保持。
- **在文件资源管理器中显示**：打开该目录。
- **在磁盘上新建文件夹**：只创建指定父目录下的新子目录，拒绝越界名称、系统保留名和覆盖已有目录。空目录不进入库树，添加照片后显示。

磁盘重命名、移动现有文件夹和“将所选照片移到此处”仍沿用完整版的原片保护限制，菜单显示禁用原因。用户明确选择的复制/移动归档继续使用“导入与归档…”。

同步/重新定位在确认前再次校验源文件及 catalog revision，提交为同一组可撤销操作。扫描错误时不允许批量移除缺失项；已入库原片内容改变会报告，不覆盖原记录。撤销重新定位只回退 catalog 关联，不搬动磁盘文件。

已关联到此 catalog 的工程照片会在重新定位后校验 SHA-256，更新工程原片/XMP路径并保留编辑和版本；目标缺少一致 XMP 或原片校验失败时保留原工程并提示。此前审查中发现的风格身份迁移、风格上传回执等全链路问题仍未在本次变更中解决。

## 验证

使用临时合成图片验证：递归移出/撤销/重开、文件夹颜色、同步新增与移动匹配、虚拟副本、取消、过期预览拒绝、原片变化拒绝、原 XMP 和工程路径衔接，以及新建目录名称限制。

Windows原生窗口实际右键完成同步预览/确认、递归移出、文件保留和重开；截图私有保存，不进入发行包。没有对用户真实照片执行移动测试，也没有关闭用户既有窗口。
