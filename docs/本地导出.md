# 本地导出

当前主 App 只提供本地导出。Lumina 连接、上传、草稿图集及追加入口已停用，后台旧任务也会明确拒绝，不发出联网请求。旧工程的相关回执字段保留兼容，不代表当前支持发布。

## 使用

导出页使用独立工具栏，仅包含照片选择和预览缩放，不显示修图分类、前后对比或高级编辑。选择历史成片后，可用“查看当前照片”回到待导出的修图结果。“保存工程”位于“更多”的工程与目录分组（Ctrl+S），不是导出图片。

1. 在“导出当前照片”中核对照片名，选择 JPEG 或16位 TIFF、保存目录；GPS默认不保留。
2. 导出完成后，“本地导出历史”保存文件路径、原片/编辑指纹与成片SHA。点击记录查看实际成片；历史预览与当前修图照片分开。
3. “另存副本”复制所选历史文件，保持格式与原字节，并记录新的路径。“移除记录”只移除工程记录，磁盘文件保留。

历史随工程保存；未保存的工程或历史会显示保存标记，正常关闭前可保存。重新打开工程后可重选历史。文件离线、被移动或修改时记录仍保留，但拒绝将其他字节当作旧成片预览/复制。普通导出、风格PNG/JPEG及副本均禁止覆盖已有目标。

AI风格导出也进入本地历史，并保留风格版本标识；它是独立成片。后台完成只添加记录，不抢走用户正在查看的照片或历史选择。不需要真实AI密钥即可验证本地导出，但本地协议夹具不代表真实生成效果。

## 取消与完成

计算阶段可以取消，界面等待后台确认；取消不递增任务ID或丢弃回执。保存工程在原子替换前、导出/副本在创建目标文件前进入提交阶段，与取消通过原子状态互斥。提交开始后取消按钮禁用并显示“正在写入”，正常关闭也等待完成，保留成功或失败回执。

目录管理等会修改持久状态的任务按整体保护，不在中途取消提交。强制终止进程/断电不能等同于正常取消；本轮没有声明文件系统与工程回执是跨文件崩溃原子事务。

## 内容与隐私

### 上游复用

普通照片导出复用固定版本 LightCraft 的 `ExportOptions`、`encode_with_metadata` 和 `encode_deep`：由上游统一处理 JPEG/TIFF 编码、ICC、元数据与打印分辨率，不另建 PhotoCraft 文档转换链路。JPEG写入EXIF与XMP，TIFF写入XMP；两者保持相同的隐私过滤。JPEG 保持质量94、4:4:4，TIFF保持16位、Deflate，均为sRGB；打印分辨率采用上游默认240 PPI，不改变像素尺寸。当前界面不增加新参数。

LuminaCraft负责渲染后的人像修饰、用户XMP合并和隐私过滤，以及取消/提交互斥、禁止覆盖和历史回执。编码入口接收已过滤的元数据；不能直接改用上游Session整图导出，否则会绕过主App的独立修饰。AI风格成片和“另存副本”保持原有文件复制流程，不重新编码。

### 保留的边界

- 编辑指纹包含外部LUT内容、XMP快照及已有降噪引用。导出准备前后检查指纹，历史回执使用实际导出时的值；AI风格保留实际提交输入的指纹，不在网络等待结束后取新的LUT状态。
- 旧成片始终由其文件SHA核验；LUT更新不会把旧JPEG重新标成新版本。资源缺失时明确报错。
- 原片元数据与导入XMP按用户字段优先合并，包含标题、作者、版权、关键词、地点和可访问说明；导出尺寸与朝向更新为成片值。并非声明完整Adobe私有字段兼容。
- 关闭GPS保留时，在合并之后移除GPS和城市/地区/国家/具体地点；始终移除设备序列号、镜头序列号和人脸区域。保留原片与原XMP字节。
- 历史预览只缩小，不将小图放大到1800px；不会将编辑参数再次应用到已导出的文件。
