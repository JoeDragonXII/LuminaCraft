# 统一修图工作台

基础/人像页右侧下方现有[操作历史](操作历史.md)，复用既有撤销/重做栈，支持步骤点击回退、重做和分支。标注“本次会话”，不与保存的工程版本或AI生成版本混淆。

当前导出功能以[本地导出](本地导出.md)为准。Lumina连接/发送已暂停，旧网络回执只保留工程兼容。导出页现提供实际成片历史、预览和另存副本；下文早期迁移记录中保留的Lumina入口描述不再代表当前界面。

本轮将原“调色 / 人像 / 流程 / 风格化”收拢为同一照片上下文中的三个入口：

- **修图－基础**：白平衡、光线、色彩、曲线、裁剪与旋转、XMP、处理流程和工程版本。
- **修图－人像**：区域识别、磨皮、肤色、局部蒙版与修复。
- **修图－风格**：内置地图风格、自定义风格、生成前后对比、历史成片和导出。

修图页左侧竖排选择类别，右侧随类别切换参数；照片选择、缩放和画布组件共用。导出页有独立工具栏，只提供照片选择、翻页、缩放和历史预览返回当前照片，不显示修图分类、前后对比或高级编辑。

顶部固定照片库、修图、导出三个主入口。“保存工程”、新建/打开工程及“目录”集中到“更多”的工程与目录分组；保存工程明确保存参数和历史，不是图片导出，Ctrl+S继续可用。未保存时“更多”显示圆点提示，菜单内显示星号。撤销重做只在照片库与修图页出现。照片库、导出与主 App 弹窗保持相同浅色外壳、字体和圆角。

导航反馈为150ms底色过渡，按下立即反馈，键盘焦点独立可见。选中和未选中分别在各自颜色范围内过渡，避免文字和背景同时反色时经过低对比的中间状态；增加覆盖过渡过程文本对比度的回归。Windows关闭客户端动画或设置`LUMINACRAFT_REDUCED_MOTION=1`时即时切换。导航不让照片滑动、缩放或淡出，也不通过面板宽度动画反复改变照片尺寸。

返回“修图”恢复离开时的基础/人像/风格分类。基础与人像互切以及往返照片库/导出保留当前照片、缩放和现有预览，避免重复渲染；必要的调整前预览回到成片时仍重新渲染。后台生成任务与回执继续绑定提交照片，不随导航重启。撤销重做在照片库操作目录记录，在修图页操作当前照片参数，并按实际历史显示禁用状态。阻塞任务期间主导航禁用。

照片库有新的明确选片时，顶部“修图”/“导出”直接载入该活动照片；已有照片沿用工程内参数，新照片追加到当前工程。混合多选在异步载入后仍以提交时活动照片为中心，不跳到最后导入项。没有新选片的往返只恢复原工作上下文，不用照片库的旧选择覆盖编辑页翻到的新照片。选择快照和待载入焦点只在内存保存，不变更工程格式。

翻页按钮与照片序号同一行居中；缩小、适应/当前比例、放大为等高单行。侧栏收放、菜单、星级等使用`src/chrome.rs`的共用图标/文字控件与上游矢量图标、egui Popup。键盘和选中反馈立即呈现，悬停最多120ms，不给高频操作添加位移或尺寸动画；减少动效设置继续有效。底栏只保留必要任务与元数据反馈，避免重复显示同一预览消息。

共用视觉与导航组件集中在`src/chrome.rs`。照片库侧栏保留文件夹/相册等原有结构；窄窗口默认将右侧选片栏收为图标，可随时展开，筛选/排序/视图工具可换行，网格列宽按实际内容区域计算。导出复用工作台的照片选择、缩放、画布及可收起右栏。随附完整上游UI保持独立，未修改vendor或将其整体改造。

统一的是导航、照片上下文和界面组件：基础/人像仍保存非破坏参数，AI 风格仍是独立成片，不把生成结果自动当作原片，也不覆盖原片或 XMP。旧工程、流程文件与生成回执不需要格式迁移。

## 截图审查与调整

2026-10-16 细节复核：编辑页去掉面板默认分隔线、外框、重复分组横线及折叠区域竖向引导线，以底色和留白分组。保留风格选中边框、键盘焦点和必要的画笔/曲线反馈。圆角集中为外壳16px、卡片/状态区12px、按钮/输入/图片8px；状态、顶部操作和右栏标题按已知行高居中，参数行固定30px使滑杆与数值框中心对齐，地点输入显式垂直居中。风格卡片的选中/悬停/焦点使用同一实际卡片矩形，边框不改变卡片尺寸。

| 调整前 | 调整后 | 原因 |
|---|---|---|
| 四个顶层编辑标签，画布与照片工具各自分布 | 三个竖排修图入口，共用工作台 | 减少横向切换与重复布局 |
| 双层顶部导航占据看图空间 | 单行工程操作栏，类别留在左侧 | 保留更多照片高度 |
| 侧栏偏窄，辅助文字过小 | 左侧196px；右侧大窗320px、窄窗288px；正文14px、辅助12px | 保持可读性和共同对齐线 |
| 控件大小和历史版本行高不一 | 类别/当前成片40px，常规按钮34–38px，地点输入36px；基础/人像数值框统一68px | 统一点击区域与垂直节奏 |
| 收起栏把“操作”挤成竖字 | 64px窄栏中的36px图标按钮，保留提示及可访问名称 | 避免文字断裂并保持可展开 |
| 风格卡片缩略图小、文字密 | 208px卡片，更大的摄影区域和14px风格名 | 让图像与名称更易辨认 |
| 流程展开后展示内部JSON | 人类可读步骤，仍需显式确认执行 | 用户能理解实际参数变化 |

类别行复用 owned upstream 的原生图标，提供明确选中背景、键盘焦点边框和150ms悬停背景过渡。基础/人像保留深灰画布和原来的坐标映射；人像笔触通过当前图像矩形和渲染几何反投影回来源坐标。

按 Taste-Skill 的截图审查方式复核视觉焦点、共同对齐线、层级和内容完整性；应用页面不套用其营销网页的首屏/滚动编排或图片数量要求。Rust原生页面没有DOM，不运行或宣称通过网页专用的lint/inspect工具。

按 Motion 的通用最佳实践保持反馈短促、可中断且不改变布局。仅类别背景、卡片悬停边线与原生折叠控件反馈使用动画；照片、数值和画笔落点不添加位移/缩放动画。`src/native_motion.rs`只读查询Windows客户端区域动画偏好，在活跃绘制时至多每两秒刷新一次缓存；关闭动画时过渡立即完成，等待仅显示阶段文字，不旋转加载标记。`LUMINACRAFT_REDUCED_MOTION=1`可用于复验，不修改系统设置或工程格式。

## 参考与实现边界

用户已选择保留 Rust/egui，未引入 React、WebView 或 npm 运行时。

- [Aceternity Sidebar](https://ui.aceternity.com/components/sidebar)：参考清晰的侧栏分组、选择态与收起入口；没有直接安装 React 组件。
- [Taste-Skill](https://github.com/Leonxlnx/taste-skill)：参考现有项目先审查再改进的方式，以及克制配色、字体层级、共同基线和焦点状态；未安装或修改全局 skills。
- [MotionSites](https://motionsites.org/)：作为视觉与交互灵感来源，取适合修图工具的低干扰反馈，未复制付费模板或图片。
- 本地 `design-taste-frontend` 与 `motion` Skill：读取其视觉复核、动画时长、性能和减少动画指导，按原生App适用范围落地。Motion MCP未连接；未调用MotionScore或网页过渡编辑器，也未引入`motion/react`。

风格示意样片与原生测试截图沿用已有授权与私有验证边界；示意图、本地协议夹具均不代表真实 AI 生成效果。


调参预览保持照片画布尺寸稳定：全局底栏固定36px，普通预览不显示加载动画或全局取消按钮；长任务的取消与写入保护仍保留。两个原生窗口尺寸的逐帧坐标回归见 verification/private/preview-stability-native.ps1，仅使用临时合成照片。
